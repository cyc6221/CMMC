{% include math/ai/openai-result.html num="004" %} {% include gh-link.html href="https://github.com/openai/math/tree/main/preprints/Hilberts-tenth-problem-over-the-rational-numbers-October-6-2026" label="preprint" aria_label="preprint: Hilbert’s tenth problem over the rational numbers on GitHub" %}

No algorithm decides whether an integer-coefficient polynomial in an arbitrary number of variables has a rational zero, resolving Hilbert's tenth problem over $\mathbb{Q}$ negatively.

  • 2-converse: for elliptic curves over $\mathbb{Q}$ with nonzero rational two-torsion, a $2^\infty$-Selmer corank of zero or one equals the analytic and Mordell–Weil ranks and forces a finite Shafarevich–Tate group. {% include gh-link.html href="https://github.com/openai/math/tree/main/preprints/A-pointwise-2-converse-for-elliptic-curves-with-rational-two-torsion-October-7-2026" label="preprint" aria_label="preprint: A pointwise 2-converse for elliptic curves with rational two-torsion on GitHub" %}

{% include math/ai/openai-result.html num="143" %} {% include gh-link.html href="https://github.com/openai/math/tree/main/preprints/uniform-bounds-for-planar-polynomial-limit-cycles-September-24-2026" label="preprint" aria_label="preprint: Uniform bounds for planar polynomial limit cycles on GitHub" %}

The number of isolated periodic orbits of a real planar polynomial vector field is bounded by a finite constant depending only on its degree, resolving the uniform boundedness assertion in Hilbert's sixteenth problem.

  • quintic Liénard: every classical Liénard system $\dot x=y-F(x)$, $\dot y=-x$ with $F$ a real polynomial of degree at most five has at most two isolated periodic orbits, and the bound is attained. {% include gh-link.html href="https://github.com/openai/math/tree/main/preprints/two-limit-cycles-for-quintic-lienard-systems-September-24-2026" label="preprint" aria_label="preprint: Two limit cycles for quintic Liénard systems on GitHub" %}

{% include math/ai/openai-result.html num="378" %} {% include gh-link.html href="https://github.com/openai/math/tree/main/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026" label="preprint" aria_label="preprint: The Exponential Time Hypothesis is False on GitHub" %}

notes {% include note-link.html href="/articles/Math/others/exponential-time-hypothesis/" label="Exponential Time Hypothesis" %} {% include note-link.html href="/articles/Math/ai/openai/disproof-of-eth/" label="Disproof of the ETH" %}

For every fixed $k\ge2$, a deterministic algorithm counts the satisfying assignments of a $k$-CNF with $n$ variables and $m$ clauses in time $(n+m)^{O_k(1)}2^{n/(\log n)^{1/2+o(1)}}$ and polynomial space. It yields superlinear circuit lower bounds for a language in $\mathsf{E}^{\mathsf{NP}}$ on infinitely many input lengths.

  • ETH: refutes the Exponential Time Hypothesis, which postulates that deciding 3-SAT on $n$ variables requires $2^{\Omega(n)}$ time.
  • Review: an independent working group led by Russell Impagliazzo, Ramamohan Paturi and Ryan Williams will examine and explain the proof. At its request, the materials were made public immediately.
