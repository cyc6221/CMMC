notes {% include note-link.html href="/articles/Math/ai/openai/quasi-riemann-hypothesis/" label="The Quasi-Riemann Hypothesis" %}

Every Dirichlet $L$-function, including $\zeta(s)$, is zero-free in $\mathrm{Re}(s)>7/8$. The same half-plane is zero-free for every finite-order Hecke $L$-function over $\mathbb{Q}(\sqrt{-3})$.

{% include math/ai/openai-result.html num="004" %} {% include gh-link.html href="https://github.com/openai/math/tree/main/preprints/Hilberts-tenth-problem-over-the-rational-numbers-October-6-2026" label="preprint" aria_label="preprint: Hilbert’s tenth problem over the rational numbers on GitHub" %}

No algorithm decides whether an integer-coefficient polynomial in an arbitrary number of variables has a rational zero, resolving Hilbert's tenth problem over $\mathbb{Q}$ negatively.

  • Companion preprint {% include gh-link.html href="https://github.com/openai/math/tree/main/preprints/A-pointwise-2-converse-for-elliptic-curves-with-rational-two-torsion-October-7-2026" label="2-converse" aria_label="preprint: A pointwise 2-converse for elliptic curves with rational two-torsion on GitHub" %}: for elliptic curves over $\mathbb{Q}$ with nonzero rational two-torsion, a $2^\infty$-Selmer corank of zero or one equals the analytic and Mordell–Weil ranks and forces a finite Shafarevich–Tate group.

{% include math/ai/openai-result.html num="005" %} {% include gh-link.html href="https://github.com/openai/math/tree/main/preprints/Catalans-constant-is-irrational-September-24-2026" label="preprint" aria_label="preprint: Catalan's constant is irrational on GitHub" %}

Catalan's constant $G=\sum_{j\ge0}(-1)^j/(2j+1)^2$ is irrational.

{% include math/ai/openai-result.html num="109" %} {% include gh-link.html href="https://github.com/openai/math/tree/main/preprints/Integer-multiplication-below-n-log-n-September-23-2026" label="preprint" aria_label="preprint: Integer multiplication below n log n on GitHub" %}

notes {% include note-link.html href="/articles/Math/ai/openai/integer-mult-bounds/" label="CrocSwap integer-mult-bounds" %}

Deterministic $O(n(\log n)^{1-\kappa})$ time with $\kappa=2^{-182}$ on a multitape Turing machine, disproving the Schönhage–Strassen $n\log n$ optimality conjecture in that model.
